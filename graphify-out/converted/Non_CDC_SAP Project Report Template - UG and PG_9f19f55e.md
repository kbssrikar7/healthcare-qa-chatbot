General Guidelines for Project II Report (UG/PG/PG(Integrated))
Binding & Cover Requirements
- Cover Material: The report must have a flexible cover using white art paper with calico binding.
- Printing: All text printed on the cover must be in black ink only.
- Page Constraint: The report must contain a minimum of 60 pages and a maximum of 100 pages.
Paper Size: A4 (210 x 297 mm). The project report must be printed only on A4 sheets.
Margins: 1.5" (3.8 cm) on the left (for binding) and 1" (2.5 cm) on all other sides. (Left: 1.5", Right: 1", Top: 1", Bottom: 1")
Font Style: Times New Roman
Font Size: 12 pt for body; 14 pt for headings; 16 pt for chapter titles
Line Spacing: 1.5 lines
Alignment: Fully Justified
Page Numbering: Page numbers (numerical and Roman) must be centered at the bottom of each page.
Formatting Guidelines
Chapter Titles (Level 0): These must always begin on a new page. The standard font size is 16 pt. Chapter titles should be written in UPPERCASE (All Capitals).
Main Headings (Level 1): Use decimal numbering (e.g., 1.1 INTRODUCTION). These should be bold, set in UPPERCASE, and use a 14 pt font size.
Sub-headings (Level 2): Use two decimals (e.g., 1.1.1 Research Goals). Use Capitalize Each Word at 12 pt font size to distinguish them from main headings.
Sub-sub headings (Level 3): If your report requires deeper levels, use Bold and Italic text at 12 pt size.
Captions (Figures & Tables): Use 10 pt font for all captions. Figure captions must be placed below the image, and table titles must be placed above the table. Figures and tables should be numbered chapter-wise.
Chapter-wise Equations: Equations must be numbered chapter-wise. For example, the first equation in Chapter 2 should be written as:

Plagiarism – Similarity Report (≤ 15%) and AI Writing Report (0%) must be submitted by each team.
Note: The plagiarism report need not be bound with the project report.
Note:
Large figures, graphs, and tables may be presented in landscape orientation whenever necessary for better clarity and readability.
Each table must be confined to a maximum of two pages. Continuation of a table onto the next page is permitted only in the Literature Survey section.
The Methodology section or Project Implementation section, wherever applicable, must include a clearly written algorithm or pseudocode explaining the step by step procedure of the proposed work.

Project Report / Dissertation Submission Rules
Group Size: Each project team can have a maximum of three members for BCSE498J / CBS1904, up to four members for CSI1006 (Mini Project), individual project for CSI4901, MCSE699J.
Cover Page & Front Page: Must list all team members with their register numbers and names sorted in ascending order based on register number.
Declaration, Certificate, and Acknowledgement Pages: For group submission, these pages should include the names of all group members. A single common version of these pages must be prepared and included in the report.
Number of Copies:
If there are three members, submission of one common copy is mandatory.
One common copy must include all team members’ details on the cover page, front page, declaration, certificate, and acknowledgement pages.
There is no restriction on additional copies. Students or the guide may take extra copies if required.
