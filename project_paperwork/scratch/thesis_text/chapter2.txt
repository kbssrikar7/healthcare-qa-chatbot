Project Description and Goals Literature review Retrieval-augmented generation Lewis et al.~ lewis2020rag introduced rag as a method for improving factual accuracy on knowledge-intensive tasks. Their architecture paired a dense retriever (DPR~ karpukhin2020dpr) with a sequence-to-sequence generator (BART) and showed that conditioning generation on retrieved passages reduced hallucination on open-domain qa benchmarks. The core finding --- that output quality improves when the model reads relevant documents at query time rather than relying entirely on parametric memory --- has since been adapted across a wide range of domains. Guu et al.~ guu2020realm went further, integrating retrieval directly into pre-training. REALM is more expensive to train but produces tighter retrieval-generation coupling. Most deployed rag systems, including this one, use the simpler modular pipeline from Lewis et al., where retrieval and generation are separate components that can be swapped independently. The rag framework was chosen over fine-tuning alone for a practical reason: the knowledge base can be updated without retraining the language model. When new data is available, documents are re-indexed and the existing model continues to work. Fine-tuning alone would require retraining every time the source data changes. Medical language models BioGPT~ luo2022biogpt is a GPT-2-scale model pre-trained on 15 million PubMed abstracts and full articles. It performs well on biomedical relation extraction and named entity recognition, but was not designed for conversational qa. PubMedBERT~ gu2021pubmedbert takes a different approach: pre-training a BERT-scale model on PubMed text from scratch, rather than fine-tuning general-domain BERT. Starting from scratch avoids vocabulary mismatch and improves performance on downstream biomedical nlp tasks. ChatDoctor~ li2023chatdoctor is a LLaMA-based conversational model fine-tuned on 100,000 patient-doctor dialogues from HealthCareMagic. It generates more natural-sounding medical responses than general-purpose llms, but without a retrieval component its answers are bounded by what appeared in its training data. The ChatDoctor-HealthCareMagic dataset was used as one of the three knowledge sources in this project. BioMistral-7B~ labrak2024biomistral continues pre-training Mistral-7B on PubMed Central Open Access articles. On the MedMCQA benchmark, BioMistral-7B reaches 59.1 % accuracy against 53.2 % for the Mistral-7B base model. In the evaluations described in Chapter 7, BioMistral produced higher ROUGE-L scores than TinyLlama (0.299 vs. 0.208) but lower keyword coverage (0.3088 vs. 0.3845) --- a difference explained by its more discursive output style. TinyLlama 1.1B~ zhang2024tinyllama was trained on 3 trillion tokens using the Llama 2 architecture. It is not a medical model. Its relevance here is purely practical: at 1.1B parameters in bfloat16 it fits in roughly 2.2 GB of ram, making it the only candidate that runs at tolerable speed on cpu hardware without quantisation. Hybrid retrieval Dense retrieval~ karpukhin2020dpr uses a bi-encoder to embed queries and documents into a shared vector space, enabling approximate nearest-neighbour search at scale. bm25~ robertson2009bm25 scores documents by term frequency and inverse document frequency with length normalisation --- a probabilistic sparse method that has been competitive in information retrieval benchmarks for decades. Neither method dominates the other across all query types: dense retrieval handles semantic paraphrasing better; bm25 handles exact term matching better. Cross-benchmark evaluations of sparse and dense methods~ ma2022hybrid have consistently shown that combining both outperforms either alone. Cormack et al.~ cormack2009rrf proposed rrf as a fusion method that merges ranked lists using only rank positions, requiring no score normalisation between retrieval systems. This project uses rrf to combine the BM25 and dense ranked lists before passing the top documents to the generation stage. Explainability and calibration Guo et al.~ guo2017calibration showed that modern neural networks are miscalibrated: their softmax confidence scores overstate certainty and do not correspond well to empirical accuracy. Platt scaling~ platt1999probabilistic corrects this post-hoc by fitting a logistic function on top of the model's raw scores using a held-out calibration set. It is straightforward to implement and performs well when the raw scores are approximately monotone with accuracy. For hallucination detection, DeBERTa~ he2021deberta fine-tuned as an nli classifier checks whether a generated answer is entailed by, contradicted by, or neutral with respect to each retrieved source. This faithfulness-checking approach was evaluated in dialogue settings by Honovich et al.~ honovich2022true and Dziri et al.~ dziri2022faithdial, both of whom found nli-based checking more reliable than overlap-based metrics for detecting factual inconsistency. Research gap No published open-source system combines all five of the following in a single deployment: cpu-compatible inference, hybrid retrieval, calibrated confidence scores, nli-based hallucination detection, and source attribution. Examining the closest alternatives makes the gap concrete: itemize li2023chatdoctor has no retrieval component and no uncertainty estimation. luo2022biogpt and PubMedBERT~ gu2021pubmedbert are classification and extraction models, not conversational qa systems. rag pipelines~ lewis2020rag are not adapted for medical safety requirements and produce no domain-specific confidence signals. guo2017calibration typically operate on structured tasks with definite correct answers, not open-ended medical questions. itemize The gap this project addresses is a locally deployable, privacy-preserving medical qa system that returns grounded answers with per-response confidence breakdowns, hallucination checks, and source attribution --- running without gpu hardware. Objectives enumerate item Build a medical knowledge base from ChatDoctor-HealthCareMagic, PubMedQA, and MedMCQA using a sentence-boundary-aware chunking strategy. bm25 and dense retrieval with rrf fusion. item Evaluate TinyLlama base, TinyLlama with QLoRA fine-tuning, and BioMistral-7B as generation backends. xai confidence scorer with Platt-scaled calibration. nli hallucination detection. rest service with a React frontend. item Evaluate on a 97-question held-out test set covering four medical query types. enumerate Problem statement Patients and caregivers seeking medical information online have no access to a locally running, privacy-preserving qa system that grounds answers in verified medical documents, attaches calibrated uncertainty estimates, and checks for hallucinations before returning a response. Existing open-source medical qa tools either depend on cloud inference or provide no mechanism for answer reliability signalling. Project plan The project ran in six phases. Phase 0 covered environment setup and a baseline performance snapshot. Phase 1 addressed local optimisations: lru caching for embeddings, BM25 pickle caching, per-stage latency instrumentation, and API startup warmup. Phase 2 evaluated BioMistral as an alternative generation backend, identifying the decoding parameter changes needed to make its output usable. Phase 3 ran on Google Colab across three sessions: Session A built knowledge base v2 using the RecursiveSentenceChunker on a tpu v5e instance; Session B ran ablation studies, calibration experiments, and full model evaluations on a T4; Session C ran the A/B comparison between knowledge base versions that confirmed the v2 gain of 0.292 keyword coverage points. Phase 4 switched the production configuration to knowledge base v2 and updated the system settings accordingly. Phase 5 covered paper and report writing. Phase 6 addressed reproducibility: Dockerfile, dependency lock file, and Makefile targets for local evaluation.
