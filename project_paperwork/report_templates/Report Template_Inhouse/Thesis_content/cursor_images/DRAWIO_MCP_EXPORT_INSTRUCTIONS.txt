Architecture diagrams generated via the official draw.io MCP (open_drawio_mermaid).
Each link opens diagrams.net with your thesis Mermaid already loaded as an editable diagram.

HOW TO SAVE HIGH-QUALITY IMAGES
1. Open the link in your browser (should open automatically when the MCP runs).
2. In draw.io: Arrange → Insert → Fit page (or adjust canvas).
3. File → Export as → PNG (or SVG for LaTeX).
   - Recommended: Border 10–20, Transparent background OFF for print, scale 2x or 300% for crisp figures.
4. Save into this folder with the suggested filenames below.
