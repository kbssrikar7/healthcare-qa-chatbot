Architecture-diagrams skill ( ~/.cursor/skills/architecture-diagrams/ ) — how it was applied
========================================================================================

Principles used (from SKILL.md)
- One main aspect per figure (skill: avoid mixing abstraction levels).
- Layered subgraphs with consistent palette (skill quick-start + DO list).
- Short node labels and limited text per line (<br/> only where it aids wrapping).
- Clear left-to-right or top-down flow; no Mermaid "A & B & C --> X" chains (skill: explicit edges).
- Sequence diagram: short messages, alt/else for cache and safety (skill sequence template).
- Deployment: environment clusters in one swimlane-style LR layout (skill deployment style).

Anti-patterns avoided (skill DON'T list)
- Removed overcrowded single-row pipelines; RAG is vertical TB stages.
- Renamed subgraph id "API" to APIL (avoids parser clashes).
- Dropped Unicode math and punctuation that break importers (Sigma, middle dot, colons in node IDs).

Sources of truth
- Mermaid sources: cursor_images/skill_refined/*.mmd
- MCP payloads: cursor_images/skill_refined/_payloads/*.json
- Draw.io MCP: user-drawio / open_drawio_mermaid (dark=false, lightbox=false for editable, print-friendly)

After opening each URL in diagrams.net (anti-overlap in the editor)
1. Select All, then Arrange → Layout → (try Vertical Tree / Horizontal Flow).
2. Drag subgraphs to add whitespace; use View → Grid if helpful.
3. Format → Style → increase font size uniformly if labels feel tight.
4. Export: File → Export as → PNG, scale 2x or higher for thesis.
