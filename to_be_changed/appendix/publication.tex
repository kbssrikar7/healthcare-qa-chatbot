\noindent\textbf{Reproducibility}

To reproduce the evaluation results from a clean environment:

\begin{lstlisting}[language=bash]
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run the retrieval benchmark (requires KB v2 to be built)
make eval-retrieval

# 3. Run the end-to-end benchmark (36 questions)
python evaluation/run_e2e_benchmark.py

# 4. Run the full RAGAS evaluation (10-question sample)
python evaluation/run_ragas_eval.py --n 10

# 5. Run the full model evaluation (97 questions)
python evaluation/run_evaluation.py \
    --model tinyllama \
    --kb-version v2 \
    --output evaluation/results/
\end{lstlisting}

\texttt{make docker-build\allowbreak{} \&\& make run} reproduces the API container. Download TinyLlama (bfloat16), the QLoRA adapter, and the BioMistral GGUF into \texttt{models/} before any full evaluation run.
